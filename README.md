1. ادخل **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder `/ (root)`
4. Save

بعد دقائق الصفحة ستكون على:
`https://songjinwoo1.github.io/shiro-kingdom/`
